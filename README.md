# Simple Interest Calculator

## Description

A simple interest calculator that calculates the interest earned on a principal amount based on the given interest rate and time period.

## Formula

**Simple Interest = (P × R × T) / 100**

Where:

* **P** = Principal Amount
* **R** = Rate of Interest (%)
* **T** = Time Period

## Example

If:

* Principal = 10,000
* Rate = 5%
* Time = 2 years

Then:

**Simple Interest = (10,000 × 5 × 2) / 100 = 1,000**

**Total Amount = 10,000 + 1,000 = 11,000**

## Features

* Calculates simple interest
* Easy to use
* Beginner-friendly project
